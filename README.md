# Ночная смена

Прототип психологического хоррора на заброшенной заправке, собранный на Vue 3,
TypeScript, Vite и Electron. Игрок принимает решение для каждого из восьми случайно
выбранных посетителей смены: отметить его как безопасного или угрозу.

## Возможности прототипа

- массив смены случайным образом собирается из 16 готовых шаблонов персонажей;
- после каждого решения звёзды перемещаются случайным образом;
- луна перемещается по небосклону, а ночь плавно переходит в раннее утро;
- осмотр лица, одежды, головного убора и поведения;
- справочник подозрительных признаков;
- кнопка укрытия для будущей или расширенной механики выживания;
- подсчёт очков, правильных решений и ошибок;
- сохранение последнего результата в `localStorage`;
- адаптивный интерфейс для desktop и mobile;
- модульная TypeScript-структура персонажей в `src/game/customers.ts`;
- интерфейс Vue 3 и оболочка Electron.

## Требования

- Node.js 18 или новее;
- npm;
- для установки зависимостей нужен доступ к npm Registry;
- Electron поддерживается на Windows, macOS и Linux.

## Запуск

Установите зависимости:

```bash
cd nightShiftAtShop
npm install
```

Запустите Vue-интерфейс в браузере:

```bash
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

Запустите Electron-приложение:

```bash
npm run electron:dev
```

Для production-сборки интерфейса выполните:

```bash
npm run build
npm run electron
```

## Как играть

1. Изучите данные посетителя в правой панели.
2. Проверьте признаки в вкладке **Справочник**.
3. Нажмите **Безопасно** или **Угроза**.
4. Для активации укрытия используйте кнопку **Спрятаться**.
5. Переживите смену из восьми посетителей, допустив не более двух ошибок.

## Расширение прототипа

- Добавить нового посетителя можно в массив `customers` в `src/game.js`.
- Новые признаки стоит вынести в отдельный модуль менеджера паттернов.
- Операции аккаунта и лидерборда можно подключить через локальную БД либо API.
- Для desktop-версии можно перенести интерфейс в Electron + Vue 3 + TypeScript.
