# Ночная смена

Простой браузерный прототип психологического хоррора на заброшенной заправке.
Игрок принимает решение для каждого из восьми посетителей смены: отметить его как
безопасного или угрозу. Внешность и поведение формируются из набора из 16 типов
персонажей. За точные решения начисляются очки, за ошибки снимаются баллы. Три ошибки
завершают смену поражением.

## Возможности прототипа

- 16 данных о посетителях и случайная выборка восьми персонажей за смену;
- осмотр лица, одежды, головного убора и поведения;
- справочник подозрительных признаков;
- кнопка укрытия для будущей или расширенной механики выживания;
- подсчёт очков, правильных решений и ошибок;
- сохранение последнего результата в `localStorage`;
- адаптивный интерфейс для desktop и mobile;
- модульная структура данных персонажей в `src/game.js`, готовая для переноса в
  `GameManager`, `CustomerManager` и `PatternManager`.

## Требования

- Современный браузер: Chrome, Firefox, Edge или Safari;
- Python 3.10 или новее — только для локального HTTP-сервера;
- Node.js и Electron не нужны для запуска этого прототипа.

## Запуск

Откройте терминал в папке проекта:

```bash
cd nightShiftAtShop
python3 -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

Для остановки сервера нажмите `Ctrl+C`.

## Как играть

1. Изучите данные посетителя в правой панели.
2. Проверьте признаки в вкладке **Справочник**.
3. Нажмите **Безопасно** или **Угроза**.
4. Для активации укрытия используйте кнопку **Спрятаться**.
5. Переживите смену из восьми посетителей, допустив не более двух ошибок.

## Расширение прототипа

- Добавить нового посетителя можно в массив `customers` в `src/game.js`.
- Новые признаки стоит вынести в отдельный модуль менеджера паттернов.
- Операции аккаунта и лидерборда можно подключить через локальную БД либо API.
- Для desktop-версии можно перенести интерфейс в Electron + Vue 3 + TypeScript.
