# Development

## Команды

- `npm install` — установить зависимости.
- `npm run dev` — запустить браузерную версию.
- `npm run build` — проверить TypeScript и собрать production-бандл.
- `npm run test` — выполнить unit-тесты.
- `npm run lint` — проверить TypeScript-лингтером.
- `npm run electron:dev` — запустить Vite и открыть приложение в Electron.
- `npm run electron:build` — production-сборка Electron.

## Добавление NPC

Характеристики NPC должны храниться в JSON. Динамическое состояние конкретного прохождения хранится отдельно от статической модели.

## Добавление диалогов

Диалоги представляются узлами, ответами и условиями перехода. Классы NPC не должны содержать текст реплик или код ветвления.

## Добавление предметов и событий

Предметы и события описываются данными с Zod-схемами. События должны проверять совместимость, кулдаун и максимальное число одновременных активных событий.

## Правило следующей фазы

Перед реализацией новой механики сначала добавляется независимый unit-тест правила, затем доменная система, а затем минимальный UI для этого правила.
